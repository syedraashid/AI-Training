# Promo Codes & Discounts

## Stacking rules
Only one promo code may be applied per order. Promo codes cannot be combined or stacked with each other, and this rule cannot be overridden manually by a support agent, even as a one-time courtesy.

## Applying codes after purchase
Promo codes cannot be applied retroactively to an order that has already been placed, even if the code was valid at checkout time and the customer simply forgot to enter it. The order must be cancelled and reordered while the code is still valid if the customer wants to use it.

## Employee and partner discounts
The employee discount cannot be combined with any promo code. Customers using a partner discount code (for example, from an affiliate or influencer) follow the same one-code-per-order rule as standard promo codes — a partner code counts as "one code" just like any other.

## Expired codes
Expired promo codes are rejected automatically at checkout with error ERR-3305. Support agents cannot manually honor an expired code under any circumstances, regardless of how recently it expired.

## Minimum order value
Most promo codes require a minimum order value, shown in the code's terms when it was issued. If the cart total drops below the minimum after a return or cancellation of one item, the discount is automatically removed from the remaining order.
